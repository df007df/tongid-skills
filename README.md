# TongID Skills

TongID 平台的 Agent 技能目录。每个技能对应 TongID 的一项业务能力，让 Agent 在你的许可下读取信息、完成维护工作，或协助团队推进日常运营。

## TongID 平台

TongID 为 Web 应用、SaaS 和浏览器扩展提供统一的账户、交易、权益与运营能力。团队可以在一个工作空间中管理多个应用，再按应用隔离用户、商品、权限和运营数据。

| 平台功能 | 提供的能力 |
| --- | --- |
| 统一身份与登录 | 托管注册和登录、邮箱验证与密码重置、Google SSO、人机验证与会话管理。 |
| 应用与团队 | 用工作空间组织多个应用，管理成员、角色分工、应用域名、品牌和认证配置。 |
| 商品、订阅与收款 | 定义固定期限的订阅套餐和一次性商品，提供结账、支付、订单与人工确认收款；订阅类再次购买会替换旧订阅权益，并支持结算与提现流程。 |
| 角色、权益与权限 | 用角色和权限描述产品能力；支持权益发放、叠加、继承、到期、撤销和最终权限计算。 |
| 用户与运营 | 管理应用用户及其状态；提供折扣码、兑换码、应用邮件、Google Analytics 与钉钉/飞书通知。 |
| 候补订阅与产品更新 | 产品尚未发布时即可通过托管 iframe 收集订阅邮箱，查看订阅状态，并发送可配置的订阅成功邮件；候补订阅者不会创建账号或获得权限。 |
| 开发接入 | 提供 TypeScript SDK、REST API、API Key、OAuth/PKCE 回调和外部用户同步能力。 |
| 看板 | 收集软件问题与建议，在管理看板持续跟进；可发布游客可访问的公开看板，让用户了解产品进展。 |

## 已发布技能

技能不是另一套平台功能，而是让 Agent 调用 TongID 已有能力的操作说明与工作流程。当前已开放：

| 对应平台功能 | 技能 | Agent 可协助的工作 |
| --- | --- | --- |
| 看板 | [`tongid-board`](./skills/tongid-board/) | 查询、分析、创建和维护看板任务；跟进处理状态；维护分类与标签；读取和调整公开看板设置。 |

### `tongid-board`：看板维护

这个技能对应 TongID 的看板功能。它让 Agent 参与从“收到问题”到“用户看见进展”的完整闭环：

- **收集与检索**：按状态、关键词、来源、分类和标签查看已有任务；也可为新的反馈创建任务。
- **问题分析**：汇总各状态、分类和来源的数据，帮助团队发现集中出现的问题并判断处理优先级。
- **处理跟进**：查看单个任务的详情与内部回复，记录处理进展，并在待处理、处理中、待验收、已完成和已关闭之间更新状态。
- **问题归类**：读取、创建、改名或清理未被使用的分类和标签，让后续检索和统计保持一致。
- **公开看板维护**：读取或更新公开看板设置，决定是否启用公开看板，以及对游客展示哪些问题进展。

涉及创建、回复、状态变更或公开配置变更时，Agent 只会在收到明确指令后执行。例如：

> 汇总最近一周待处理的问题，按来源和分类告诉我优先级。

> 为这个反馈创建任务，并标记为“处理中”。

> 回复这条任务：已修复，等待验收。

## 安装

将 `tongid-board` 安装到本机，供所有项目中的 Codex 使用：

```bash
npx skills add df007df/tongid-skills --skill tongid-board --full-depth -g -y
```

如果只希望当前项目使用，去掉 `-g`：

```bash
npx skills add df007df/tongid-skills --skill tongid-board --full-depth -y
```

安装完成后，在下一轮 Codex 对话中即可使用。

## 后续技能

TongID 的其他平台能力会陆续提供独立技能，例如身份与用户、商品与订阅、权益与权限、候补订阅与产品更新、工作空间与运营通知等。每项技能都会单独说明对应的产品功能、Agent 可执行的范围和安装方式。
